# قطعتك — طلبات توفير قطع الغيار عبر واتساب

موقع ثابت (HTML/CSS/JS) بدون قاعدة بيانات ولا خادم. يملأ العميل النموذج فتُفتح محادثة واتساب مع رقم قطعتك برسالة جاهزة، ويضغط العميل «إرسال».

## الملفات
- `index.html` `styles.css` `app.js` `i18n.js` الموقع (عربي/إنجليزي)
- `config.js` رقم واتساب (غيّره هنا فقط)

## النشر
ارفع الملفات كما هي إلى GitHub Pages أو Netlify أو Cloudflare Pages. لا إعداد إضافي.

## حدود هذا الأسلوب
- لا يوجد حفظ للطلبات ولا لوحة إدارة؛ سجل الطلبات هو محادثات واتساب نفسها.
- الطلب لا يصل إلا إذا ضغط العميل «إرسال» في واتساب.
- لا يمكن إرفاق الصور تلقائياً؛ يرسلها العميل يدوياً في المحادثة.
- رقم الطلب يُولَّد في المتصفح (للمرجع فقط، ليس مضمون الفرادة قاعدياً).

## تحسين محركات البحث (SEO)
- عنوان ووصف بالعربية، وOpen Graph، وبيانات منظمة (Organization وFAQPage) وقسم أسئلة شائعة ظاهر للزائر، وتحميل مسبق لصورة الواجهة، و`robots.txt`.
- **بعد النشر وتحديد الرابط النهائي** أضف: وسم `canonical` و`og:url` و`og:image` (روابط كاملة)، وملف `sitemap.xml`، وسطر `Sitemap:` في `robots.txt`. ثم سجّل الموقع في Google Search Console.
- بدّل اللغة داخل الصفحة نفسها بدون رابط مستقل للإنجليزية، فمحركات البحث تفهرس النسخة العربية فقط.
